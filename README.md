# Material Exploration Through Active Learning (metal)

This module defines a framework for exploring a largly unknown phase space using active learning. Specifically, the approach is inspired by a methodology proposed by [Rao et al](https://www.science.org/doi/abs/10.1126/science.abo4940). While the module is flexibel enough to more or less enable a recreation of this study, the main goal is to provide functionalities that allows for the definition of an almost fully automated process that does not require any external input. For this reason, functonalities are also provided that enables the user to base the learning cycle on data obtain through the application of efficient machine learning interatomic potentials (IAPs). Though such can be provided, and trained, by the user, the procedure described in the documentation will assume that the, universal, [M3GNet IAP](https://github.com/materialsvirtuallab/m3gnet) recently developed by [Chen et al](https://www.nature.com/articles/s43588-022-00349-3), which is fully integrated into this module. Naturallly, it is also possible to employ the same approach based on information obtained via, e.g., experiments or density functional theory calculations.
